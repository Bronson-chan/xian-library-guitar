# 弦库 · 吉他谱管理台 — 使用说明

按你给的截图 1:1 复刻的界面，数据全部来自真实读取的 157 份谱面文件（无占位、无虚构）。

---

## 一、怎么打开

**直接双击 `index.html`** 就能用，不需要装任何东西、不需要联网、不需要启动服务。

> 唯一要求：`index.html` 要和 `assets` 文件夹**待在同一个目录里**（现在就是这样），不能只把 index.html 单独拷走。

想放到手机上用，见第六节「在线发布」。

---

## 二、目录结构

```
弦库-吉他谱管理台/
├── index.html              整个应用（单文件，CSS/JS 全内联，零外链）
├── 曲谱数据总表.csv         157 条结构化数据，可用 Excel / WPS 打开直接改
├── 未识别与需确认清单.md     没能从谱面直接读出的字段逐条列明（附件清单）
└── assets/
    ├── hero.jpg            首页顶部背景图（从你的参考截图里提取）
    ├── covers/  157 张      方形专辑封面（真实唱片封面，500×500）
    ├── avatars/  90 张      歌手头像（真实歌手照片，240×240 圆形裁切）
    └── tabs/    157 张      详情页完整谱面图（最长边 2800px，保持原始排版）
```

> 封面与头像均为**真实图源**：专辑封面取自公开音乐平台的唱片封面，歌手照片取自维基百科人物图片。
> 其中《于是》（郑润泽）原封面本身就是白底极简设计，并非缺图。

## 三、界面结构与功能对照

### 左侧栏（PC）／底部 Tab（手机）
| 入口 | 内容 |
|---|---|
| 首页 | 问候语 + 搜索 + 4 个快捷入口 + 「最近在学」+「今天建议复习」 |
| 我的曲谱 | 全库 157 首，多维筛选 + 搜索 + 排序 |
| 收藏 | 收藏过的曲目 |
| 练习记录 | 累计练习数 / 连续天数 / 本月天数 + 近 5 周热力图 + 练习流水 |
| 我的标签 | **歌手墙（91 位歌手，带头像与曲目数）** + 按 曲风 / 类别 / 难度 / 拍号 四组标签分布，点即跳转筛选 |
| 功能 | 搜索 + **9 个入口卡片**（按歌手找 / 按曲风找 / 按类型找 / 按状态找 / 智能练习 / 长期未练 / 随机复习 / 拿手歌曲 / 新歌练习）+ 我的标签 + 常用歌手横滑 |
| 设置（侧栏最底部） | 导出备份 / 导入恢复 / 数据概况 / 封面与头像 / 数据来源 |

### 今天建议复习：一天锁定一组
- 首页「今天建议复习」是一行一首的紧凑列表（小封面 + 曲名 + 歌手 + 标签 + 「复习」按钮），
  不再是占地方的大卡片。
- **一天只自动换一次**：切到别的页面再回来、刷新页面，这三首都不会变。
- **练完一首回来，另外两首还在**：只有你练过的那首会从列表里退出，不会被随机顶替。
- 想立刻换一组，点右上角「**随机换一组**」——那是当天的新一组，不会自己再变。
- 第二天打开自动生成新的一组。

### 我的曲谱：两种视图（右上角一键切换）
- **列表视图（默认）**：一行一首 —— 小封面 + 曲名 + 歌手 + 标签 + 练习状态，一屏能看 12 首左右，翻页最省力
- **网格视图**：大卡片 + 专辑封面，想看封面时切过去

### 多维筛选与排序（「我的曲谱」页）
- **搜索**：曲名 + 歌手，实时过滤
- **全部歌手**：下拉，按歌手筛选
- **全部曲风**：流行 / 民谣 / 摇滚 / 经典
- **全部类别**：国语 / 粤语
- **全部难度**：简单 / 中等 / 进阶 / 困难
- **全部状态**：未练习 / 正在学 / 我会了
- **默认顺序**：可切换排序方式

### 专辑封面与歌手头像（全部为真实图源）
- **157 张专辑封面全部是真实唱片封面**：按「曲名 + 歌手」双重匹配取到该曲所属专辑的原图
  （500×500，取自公开音乐平台曲库与 Cover Art Archive）。
- **91 位歌手头像全部是真人照片**，且 **90 张互不相同**。来源按「公开音乐平台歌手主页 →
  百度百科词条人像 → QQ 音乐歌手头像 → 维基百科人物图片」四级回退，取到的图还会校验
  是否为平台默认占位图、是否与他人重复。列表、卡片、详情页、歌手墙、「常用歌手」横滑列表
  统一使用。
- **都能自己换**：卡片右下「···」→「更换专辑封面 / 更换歌手头像」，或在详情页点封面
  上传。选图后自动居中裁剪成正方形并压缩，存在本机浏览器。
- 「设置 → 封面与头像」可看已自定义的数量与占用空间，也能一键恢复默认。

### 详情页（接近全屏）
点任意卡片进入，包含：
- 顶栏：返回 / 方形封面（点它可换封面）/ 曲名 + 歌手头像与原始文件名
- **谱面按全屏宽度铺开**（页面只留 8px 边距），默认「适应宽度」即占满可用宽度，小字也看得清
- 「适应宽度 / − / + / 原图」缩放控件，最大可放大到 400%
- 右上「收藏」与「完成本次练习」按钮
- 「上一首 / 下一首」按当前筛选结果顺序翻页

## 四、数据从哪来（157 份全部逐份读取）

| 字段 | 来源 |
|---|---|
| 曲名 | **谱面头部印刷文字**为准（文件名冲突时以谱面为准，见清单表 C） |
| 歌手 | 谱面印刷的「原唱 / 演唱」 |
| 调式 1=X | 谱面印刷的调号 |
| 原调 | 谱面印刷的「原调」 |
| 变调夹 | 谱面印刷的 Capo 标注（含「降半音调弦」等特殊写法，原样保留） |
| 拍号 | 谱面印刷（155 份 4/4，1 份 6/8） |
| 曲风 / 类别 / 难度 | 谱面不印刷，按曲目风格、演唱语言、和弦与节奏复杂度**推断** |

统计口径：曲风 流行 120 / 民谣 13 / 摇滚 12 / 经典 11；类别 国语 138 / 粤语 18；
难度 中等 108 / 简单 31 / 进阶 12 / 困难 5；拍号 4/4 共 155、6/8 共 1。

## 五、哪些字段不是谱面原文（重要）

**未识别字段：0 项** —— 157 份的曲名、调式、拍号全部直接从谱面读出，没有空缺。

但有三类需要你过目，详见 `未识别与需确认清单.md`：

共 **38 条**，分四类（页面「功能 → 查看未识别清单」可弹出完整列表）：

- **已推断 33 项**：27 位歌手的谱面头部没印演唱者，按该曲通行原唱推断（如
  `不能说的秘密 → 周杰伦`、`成都 → 赵雷`）；另有 4 处调式写法异常、2 项整体字段。
  **这些是推断值，不是谱面原文。**
- **需确认 1 项**：`至少还有你.jpg`，谱面印的是「张国荣」，但该曲更常见的原唱标注是
  「林忆莲」（张国荣有翻唱版）。目前按谱面原文保留，你要改就改。
- **文件名与谱面不一致 3 项**：已采用谱面印的曲名 ——
  `不浪漫的罪名.jpg → 不浪漫罪名`、`匿名的朋友.jpg → 匿名的好友`、
  `海阔天空C调.jpg → 海阔天空（C调版）`。
- **已识别但值得一提 1 项**：`单身情歌.jpg` 是全部 157 份里唯一一份 6/8 拍。

改数据不用碰代码：直接编辑 `曲谱数据总表.csv` 再按需同步即可，或告诉我你要改哪些，我来改。

## 六、进度与收藏怎么存

练习次数、最近练习日期、学习状态、收藏，都存在**浏览器本地**（`localStorage`，键名
`wb_xiangu_v1`）。

这意味着：清掉浏览器数据会丢；换设备/换浏览器也不同步。所以：

- 首屏顶部有提示「全部数据存在本机浏览器，建议定期导出备份」
- 「功能」页有 **立即导出备份**（存成 JSON）和 **选择备份文件**（导入恢复，不限条数）
- 页尾另有「清空全部学习数据」，点了会二次确认

注意两点：

- **谱面、曲名、歌手是写死在页面里的**，清空学习数据只会清掉练习记录、状态和收藏。
- **你自己换过的封面和头像也会保留**（它们属于个性化设置，不算学习数据）。
  「清空全部学习数据」的确认框里已写明。
- 导出/导入备份会**连同自定义封面与头像一起迁移**，换电脑不用重新找图。

## 七、在线链接

**https://guitar-tabs-72292.app.workbuddy.host/**

电脑/手机浏览器直接打开就能用，**不需要登录**。本地那份 `index.html` 照样可以双击打开，
两者功能完全一样，只是线上的那份可以在任何设备上访问。

三点必须知道：

1. **链接是公开的**——技术上任何人拿到它都能打开。虽然网址足够长、没人猜得到，
   但我不会把它发给任何人；**也请你别转发到群、论坛或任何公开场合**。
   你这 157 首里绝大多数是正式出版曲目，公开传播有侵权风险。
2. **进度只存在各自的浏览器里**。在电脑上点的「完成本次练习」、收藏、学习状态，
   换到手机上看不到，反之也一样。要跨设备同步目前只能靠「导出备份 → 导入恢复」。
3. 谱面图共 75MB、封面 6MB、头像 0.8MB，但**打开一首只读一张图**，不会一次性全下，
   不用担心流量。首次打开首页会读几张封面，之后就都在浏览器缓存里了。

不想要这个链接了，跟我说一声，我一键下线，链接立刻失效。

## 八、已知的边界

- **封面与头像已全部换成真实图源**：157 首全部配到对应专辑的真实唱片封面，91 位歌手
  全部配到真实照片（取自公开音乐平台的唱片封面与维基百科人物图片）。
  其中 138 首封面来自音乐平台曲库、17 首因平台缺版权改用 Apple Music 曲库、
  1 首（《枫》）取自 MusicBrainz/Cover Art Archive、1 首（《蒲公英的约定》）取自电影原声带专辑封面。
  这些都是**你自己电脑上的本地文件**，页面不依赖任何外部图床，断网也能看。
  仍然可以随时用「更换封面 / 更换头像」换成你更喜欢的图。
- **谱面是图片**，所以文字不能选中、不能复制；如需可搜索的文字谱，得另做一套文本谱库。
- **不联网**：没有云端同步，没有多人协作，数据只在本机。
- **界面按参考截图复刻**：主色 `#FF6422`，浅橙填充 `#FFF0E2`，页面底 `#F8EFE4`，
  卡片圆角、间距、图标风格均按截图取样还原；只有「我的曲谱」「练习记录」等截图里
  没出现的页面，是按同一套设计语言延展出来的。
